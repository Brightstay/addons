# Add-ons Brightstay

Programmes installés dans les boîtiers des logements équipés par [Brightstay](https://brightstay.fr).

## Ajouter ce dépôt

Home Assistant → **Paramètres → Modules complémentaires → Boutique → ⋮ → Dépôts**, puis :

```
https://github.com/Brightstay/addons
```

## Contenu

- **[Brightstay Hub Agent](bs_hub_agent)** — relie le logement à Brightstay.
